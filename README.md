# 미로 탈출 게임 (C)

C 언어로 만든 콘솔 미로 탈출 게임입니다.
플레이어(`@`)를 W·A·S·D로 움직여 벽(`#`)을 피해 출구(`E`)를 찾습니다.

## 주요 기능

- **캐릭터 이동**: W(위) / A(왼쪽) / S(아래) / D(오른쪽)
- **벽 충돌**: 벽이 있는 칸으로는 이동 불가
- **2스테이지**: 첫 미로를 탈출하면 두 번째 미로 시작
- **기록**: 스테이지별 이동 횟수, 전체 이동 횟수 출력
- **포기**: Q 입력 시 종료

## 조작 방법

| 키 | 동작 |
|---|---|
| `w` | 위로 이동 |
| `a` | 왼쪽으로 이동 |
| `s` | 아래로 이동 |
| `d` | 오른쪽으로 이동 |
| `q` | 포기 |

키를 입력하고 Enter를 누르면 이동합니다. `dddd`처럼 여러 개를 한 번에 입력하면 연속으로 이동합니다.

## 실행 방법

### Visual Studio

1. 빈 프로젝트 생성 후 `maze.c` 추가
2. `Ctrl + F5`로 실행

> 한글이 깨지면 **파일 → 다른 이름으로 저장 → 인코딩하여 저장 → 한국어(코드 페이지 949)** 로 저장하세요.

### gcc

```bash
gcc maze.c -o maze
./maze
```

## 사용 기술

- C
- 2차원 배열(미로), 3차원 배열(스테이지 묶음)
- while, for, if-else
- 전처리기 `#ifdef`로 윈도우 / 리눅스 화면 지우기 구분
